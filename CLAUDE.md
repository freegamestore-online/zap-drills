# Zap Drills

A free game on FreeGameStore.

- Subdomain: `Zap Drills.freegamestore.online`
- Dev: `pnpm install && pnpm dev`
- Build: `pnpm build`
- Deploy: `git push origin main` (auto-deploys to R2 via GitHub Actions)
